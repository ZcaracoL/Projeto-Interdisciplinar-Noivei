Tabelas sugeridas para o banco relacional (SQL):

1) usuarios
- id (PK, inteiro, auto-increment)
- nome
- email
- senha
- telefone
- tipo (cliente ou fornecedor)
- criado_em

2) fornecedores
- id (PK, inteiro, auto-increment)
- usuario_id (FK para usuarios.id)
- nome_loja
- descricao
- foto_url
- contato_email
- criado_em

3) planos
- id (PK, inteiro, auto-increment)
- fornecedor_id (FK para fornecedores.id)
- titulo
- descricao
- preco
- criado_em

4) categorias (opcional)
- id (PK, inteiro, auto-increment)
- nome
- criado_em

5) fornecedor_categoria (opcional)
- id (PK, inteiro, auto-increment)
- fornecedor_id (FK para fornecedores.id)
- categoria_id (FK para categorias.id)

Obs:
- clientes não precisam de loja ou planos.
- cada fornecedor pode ter vários planos.
- cada usuário só deve poder editar o próprio perfil/loja.
